# Dev-Weekends-Assignment-1

Full-stack food ordering demo with a React frontend and an Express + SQLite backend.

## Prerequisites

- Node.js 20+ and npm

## Install

From the repo root:

1) Install backend dependencies

```
cd Backend
npm install
```

2) Install frontend dependencies

```
cd ..\Frontend
npm install
```

## Run

Option A: Use the helper script (Windows)

```
run-dev.bat
```

Option B: Two terminals

Terminal 1 (backend):

```
cd Backend
npm run dev
```

Terminal 2 (frontend):

```
cd Frontend
npm run dev
```

Backend API base URL: http://localhost:3000/api

Frontend dev server: http://localhost:5173
